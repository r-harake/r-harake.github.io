# Rawad Al Harake · Portfolio

## View the draft

Open [the offline preview](portfolio-preview.html) and choose **Download raw file** in GitHub’s file toolbar. Open the downloaded HTML file in a browser. It includes the artwork and interactive controls. The publication links need an internet connection.

## Update the site

Edit the copy and publication entries in docs/index.html. The images are in docs/assets, the layout is in docs/style.css, and the wing-detail control is in docs/interaction.js. Open docs/index.html in a browser to view current edits. The standalone preview is a snapshot of this review version.

The dragonfly is an AI-generated editorial illustration. The aircraft wing and enclosure drawings are original schematics.

## Hosting

The docs folder is ready for GitHub Pages when the owner approves publication.
